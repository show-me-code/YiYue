## 本轮修正的缺陷（均先复现、后修复、再回归）

1. **作者自带的 `.bbl` 没被用上 → 全篇 35 处引用变成 `(?)` 并丢失整页参考文献**
   arXiv 包内 `main.bbl` 与 `\bibliography{alain17a}` 名字不一致；仅改名无效——Tectonic
   见到 `\bibliography` 会自己跑 BibTeX，用不存在的 `.bib` 覆盖 `.bbl`。改为把作者的
   `.bbl` 对齐命名并改写成 `\input{alain17a.bbl}`，且必须在译文写盘之后再改写
   （否则被翻译步骤覆盖回原样）。
2. **修复逻辑吞掉占位符两侧花括号 → `\hbox{$x \mapsto x+r(x)$}` 变成 `\hbox$x…$`**
   编译报 `Missing { inserted.`，触发"整节退回英文"的静默降级（Experiments 整节没翻译）。
   恢复占位符时只替换占位符本身，并在恢复后比对花括号/`$` 计数。
3. **ctex 注入放大行距 → 页数 12→14**，与"保住原版版式"冲突。记录并还原
   `\baselinestretch`，页数与页内字符数回到与原始源码编译一致。
4. **作者自己的 `\renewcommand{\figurename}{Figure~}` 覆盖了汉化**，图注标签又变回
   "Figure 1"。汉化块移到导言区末尾（`\begin{document}` 之前）执行；样式文件里
   硬编码的 `{\large\bf Abstract}` 单独补丁为「摘要」。
5. **图注漏译**：`\captionof{figure}{...}`、`\subcaption{...}` 用正则抽取时整条漏掉；
   子图注 `\subfloat[...]` 位于受保护的 figure 环境内，走不到 caption 通道。
   改用花括号配平解析 + 末尾兜底补译（章节标题同样兜底，修掉 `1 Introduction` 这类漏译）。
6. **验证器本身的两个盲区**：只比对条目数量发现不了"整节退回英文"，也无法区分
   "作者原版瑕疵"与"我们引入的溢出"。补充语言残留检查（成句英文 / 英文图表标题）、
   以版心为基准的溢出判定、以及"与基线一致的溢出一律按原版瑕疵保留"的口径。
7. **既有 bug（非本轮引入）**：术语表快照缺 `enabled` 字段，导致任何带术语表的任务
   都会以 `'SimpleNamespace' object has no attribute 'enabled'` 失败。已修复并补测。
