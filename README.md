# 译阅 YiYue

本地 PDF 学术论文翻译工作台：上传 PDF（或只填 arXiv ID），用**你自己的 LLM API** 翻译成中文，保持原版式，浏览器里对照阅读。

## 功能

- **双引擎翻译**：arXiv 论文走「LaTeX 源码直译重编译」（排版与原版一致）；任意 PDF 走原位排版（BabelDOC），失败自动回退
- **逐段对照阅读**：英文段落在前、中文译文紧随，公式 KaTeX 渲染、引用角标、插图内联；阅读底色可选（深色/纸白/羊皮纸/护眼绿）
- **AI 阅读助手**：基于论文全文的多轮问答（Markdown 渲染），内置总结/大纲/学习指南/FAQ 模板，会话按论文保存
- **双栏对照**：左右同步滚动、缩放、仅译文模式
- **术语表 + 翻译风格**：术语注入保证译法一致；可选 默认学术/忠实直译/流畅润色/通俗易懂
- **任务管理**：论文标题与主题词自动生成、归档页（搜索/主题筛选）、进度实时可见、缓存复跑秒出
- 多 API 配置档（OpenAI / Anthropic 协议兼容），翻译完成自动闭环验证并出报告

## 快速开始

Windows 双击 **`启动译阅.bat`**（macOS/Linux 用 `scripts/start.sh`），浏览器打开 http://127.0.0.1:8000。

1. 「API 配置」填 Base URL / API Key / 模型名，测试连接
2. 「翻译任务」拖入 PDF 或填 arXiv ID，开始翻译
3. 完成后进入阅读器，可下载译文 / 双语 PDF

依赖：Python 3.12、[uv](https://docs.astral.sh/uv/)、Node.js ≥ 18。

## 说明

- 翻译质量取决于你选用的模型；本仓库不内置模型
- 内置 BabelDOC 为 AGPL-3.0：自用/自托管无碍，对外提供网络服务需按 AGPL 开源
